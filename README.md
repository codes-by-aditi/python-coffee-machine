# Coffee Machine Program ☕

## Description
A console-based coffee machine simulator built using Python.
The program manages resources, processes coin-based payments,
and prepares drinks based on user input.

## Features
- Espresso, Latte, Cappuccino
- Resource availability check
- Coin-based payment system
- Change calculation
- Machine report & shutdown

## Concepts Used
- Python dictionaries
- Functions
- Loops
- Conditional statements
- Modular programming

## How to Run
```bash
python coffee_machine.py
